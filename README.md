# Tic-Tac-Toe (Крестики-нолики)

Консольная и графическая версия игры "Крестики-нолики" (Tic-Tac-Toe).

## Описание

Игра для двух игроков, где они поочерёдно ставят свои знаки (X и O) на поле 3x3. Цель игры — выстроить три своих знака в ряд (горизонтально, вертикально или диагонально).

### ✨ Новая функция

Теперь игра поддерживает ввод имён игроков! Вместо стандартных "X" и "O" вы можете указывать свои имена, чтобы сделать игру более персонализированной и весёлой.

## Как запустить

### Консольная версия (Python)

```bash
python console.py
```

При запуске игра запросит имена двух игроков. Если поле оставить пустым, будут использоваться имена по умолчанию ("Игрок 1" и "Игрок 2").

### Графическая версия (Java Swing)

Запустите `SwingVersion.java` через JDK. Поддерживается настройка размера поля (3x3, 4x4, 5x5 и т.д.) и режим PvP/PvCPU.

## Правила игры

1. Игра для двух игроков.
2. Игрок X ходит первым.
3. **Введите имена игроков** при запуске игры.
4. Игроки поочерёдно выбирают свободную ячейку для своего знака.
5. Выигрывает игрок, первый выстроивший три своих знака в ряд.
6. Если все ячейки заполнены и ни у кого нет выигрышной линии — игра заканчивается вничью.
