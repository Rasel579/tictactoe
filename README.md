# Tic-Tac-Toe (Крестики-нолики)

Консольная версия игры "Крестики-нолики" (Tic-Tac-Toe), написанная на Python.

## Описание

Игра для двух игроков, где они поочерёдно ставят свои знаки (X и O) на поле 3x3. Цель игры — выстроить три своих знака в ряд (горизонтально, вертикально или диагонально).

## Как запустить

```bash
python console.py
```

## Правила игры

1. Игра для двух игроков.
2. Игрок X ходит первым.
3. Игроки поочерёдно выбирают свободную ячейку для своего знака.
4. Выигрывает игрок, первый выстроивший три своих знака в ряд.
5. Если все ячейки заполнены и ни у кого нет выигрышной линии — игра заканчивается вничью.

## Технологии

- Python 3.x
- Консольный ввод (`input()`)

## Файлы проекта

- `console.py` — основной код игры
- `SwingVersion.java` — Java-версия игры (Swing GUI)
